========================================
  空拍套疊工具  使用說明
========================================

功能:把無人機空拍照拼成完整正射底圖,並把施工圖(依圖層)以「剛體(不變形)」套疊上去。
      施工圖完全保持原形狀,只做旋轉+等比縮放+平移。

==================================================
  【你自己這台(有裝 Python)→ 雙擊「雙擊執行.bat」】← 推薦
==================================================
  直接雙擊「雙擊執行.bat」→ 黑色視窗出現選單。
  ★ 這個方式會用你電腦的 Python 跑,會跳出正常的「選擇資料夾 / 選擇檔案」視窗
    (就是你熟悉的那種對話框),不會卡住。
  (為什麼不是雙擊 .exe:PyInstaller 打包後的 exe 裡,tkinter 檔案對話框會不穩、
   甚至卡死;直接跑 .py 就沒這問題。)

==================================================
  【給沒裝 Python 的同事 → 空拍套疊工具.exe】
==================================================
  雙擊「空拍套疊工具.exe」→ 黑色視窗出現選單。
  ★ exe 版需要路徑時,把『資料夾/檔案』從檔案總管『拖進這個黑視窗』自動貼上,再按 Enter。

    [1] 拼接空拍 + 產生對位工具
        → 拖入『空拍照資料夾』→ 自動拼接
        → 拖入『施工圖 PDF』、輸入頁碼(直接 Enter=3)
        → 自動開啟 picker.html;在瀏覽器拖 4 個基地角,按【下載 points.txt】(存同資料夾)
    [2] 產出套疊圖(picker 點好、下載 points.txt 之後)
        → 依序拖入 mosaic.png、施工圖 PDF、points.txt
        → 產出 套疊.png 與 套疊_透明層.png
  (第一次啟動 exe 需幾秒解壓,屬正常)

--------------------------------------------------
一次性安裝(只有要用 .py 原始碼版才需要)
--------------------------------------------------
  pip install pymupdf opencv-python-headless pillow numpy

--------------------------------------------------
每期空拍的三步驟
--------------------------------------------------
（在本資料夾開 PowerShell / 終端機執行）

【1】拼接空拍  → 產生 mosaic.png
    python 空拍套疊工具.py stitch  "照片資料夾"
    ‧ 自動排除傾斜照(雲台俯角 > -80 度),只用近正射照
    ‧ 若所有照片都有 DJI 相對高度資料,會自動選張數最多的同高度航線,
      排除混入的補拍／相鄰地塊照片,避免出現分離圖塊與黑底
    ‧ 例:python 空拍套疊工具.py stitch "1150731"

【2】產生對位工具  → 產生 picker.html 與 圍籬編號對照圖.png
    python 空拍套疊工具.py prep  "照片資料夾\mosaic.png"  "施工圖.pdf"  --page 3
    ‧ 自動抓圍籬 4 個角;用瀏覽器打開 picker.html
    ‧ 對照右邊「圍籬編號對照圖」,把 4 個點拖到底圖對應基地角
    ‧ 完成按【下載 points.txt】(存到與 mosaic.png 同資料夾)

【3】套疊  → 產生 套疊.png 與 套疊_透明層.png
    python 空拍套疊工具.py overlay  "照片資料夾\mosaic.png"  "施工圖.pdf"  "照片資料夾\points.txt"  --page 3
    ‧ 會印出殘差(<2% 大致 OK)

--------------------------------------------------
可選參數
--------------------------------------------------
  --page N            施工圖頁碼(0 起算,預設 3 = 假設工程配置圖(一))
  --layers "A,B,C"    自訂要套疊的圖層,預設:
                      施工圍籬,洗車台,鐵絲網,鐵欄,水泥牆,S-CONCP
                      （施工圍籬含大門/勞工休息區;S-CONCP=PC樁;鐵絲網=透空圍籬）
  --fence-layer 名稱  用來抓角與畫對照圖的主圍籬層(預設 施工圍籬)
  --no-whiteout       不要自動遮除右下圖例/右側孤立虛線

--------------------------------------------------
注意
--------------------------------------------------
‧ 底圖是拼接近正射影像,非嚴格正射,殘差約 1~2%(數公尺內)。要更精準請用
  DJI Terra / WebODM 出正射影像後,同樣用步驟 2、3 套疊即可。
‧ 唯一需要人工的一步是「拖 4 個基地角」——這本來就該人工確認最可靠。
